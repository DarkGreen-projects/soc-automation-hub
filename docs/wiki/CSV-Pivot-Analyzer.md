# CSV Pivot Analyzer

Tab demo: statistiche su export CSV SIEM e query pivot one-click.

## Utilizzo

1. Tab **CSV Pivot**
2. Carica CSV con header o **Esempio CSV**
3. **Analizza** → top valori per colonna, bucket temporali
4. **Copia query** su un valore per approfondire nel SIEM

Esempio: [sample-logpoint-export.csv](https://github.com/DarkGreen-projects/soc-automation-hub/blob/main/examples/sample-logpoint-export.csv)

Le query includono esclusioni allowlist per ridurre rumore (scanner, app note).
