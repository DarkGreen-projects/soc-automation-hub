# Bulk IOC Scanner

Tab demo: classificazione bulk di IP, hash, domain e URL.

## Utilizzo

1. Tab **Bulk IOC**
2. Incolla lista o **Esempio IOC** → **Parsa lista**
3. **Anteprima demo** (web) o **Avvia scan VT** (desktop)
4. Export malevoli o report completo

## Demo vs desktop

| | Web | Desktop |
|---|-----|---------|
| VT | Simulato | Reale |
| Checkpoint | No | Sì |

Collegamento: dal **SIEM Decoder**, **Invia IOC a Bulk scan** precompila questo tab.

Esempio: [sample-ioc-list.txt](https://github.com/DarkGreen-projects/soc-automation-hub/blob/main/examples/sample-ioc-list.txt)
